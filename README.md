# 🧰 HeightConverter — تبدیل‌گر همه‌کاره

اپلیکیشن ویندوزی سبک و سریع برای تبدیل قد، وزن و واحدهای اندازه‌گیری — با رابط کاربری فارسی و طراحی مدرن.

A lightweight, fast Windows app for converting height, weight and measurement units — with a modern Persian UI.

## ✨ امکانات / Features

- 📏 **قد:** فوت و اینچ ↔ سانتی‌متر، دوطرفه و لحظه‌ای
- ⚖️ **وزن:** کیلوگرم ↔ پوند ↔ استون
- 💪 **BMI:** محاسبه شاخص توده بدنی با گیج رنگی و بازه وزن سالم
- 📐 **طول:** تبدیل کامل واحدهای طول از میلی‌متر تا مایل
- 🌡️ **دما:** سلسیوس / فارنهایت / کلوین
- 🧍 **مقایسه قد:** نمودار بدن چند نفر با اسم، جنسیت، وزن و BMI هر فرد

## 📥 دانلود / Download

آخرین نسخه را از بخش [Releases](https://github.com/Abbasowski/HeightConverter/releases/latest) دانلود کنید:

1. فایل `HeightConverter-x.x.x.zip` را دانلود کنید
2. از حالت فشرده خارج کنید
3. `HeightConverter.exe` را اجرا کنید — بدون نیاز به نصب!

Download the latest version from the [Releases](https://github.com/Abbasowski/HeightConverter/releases/latest) page — no installation required.

## 🔄 بروزرسانی خودکار / Auto-Update

برنامه هنگام اجرا خودش نسخه جدید را چک می‌کند و اگر بروزرسانی موجود باشد، دکمه سبز بروزرسانی نمایش داده می‌شود — با یک کلیک، برنامه خودش را به‌روز می‌کند.

The app checks for updates on launch and offers a one-click in-app update when a new release is published.

## 🔒 حریم خصوصی / Privacy

کاملاً آفلاین کار می‌کند — هیچ داده‌ای ارسال نمی‌شود. تنها ارتباط اینترنتی، بررسی نسخه جدید است.

Works fully offline — no data is ever sent. The only network call is the update check.

## 🛠️ ساخته شده با / Built With

- Python + [pywebview](https://pywebview.flowrl.com/)
- HTML/CSS/JS (vanilla, no frameworks)
- [PyInstaller](https://pyinstaller.org/) for packaging
